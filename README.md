# UsageEdge 시험판

공개 전 검토를 위한 소스입니다. 현재 개인용 앱과 별개이며 아직 공개 배포용 완성본이 아닙니다. Claude 계정 토큰을 읽거나 전송하지 않습니다. 선택적으로 Claude Code 상태줄이 전달한 사용량을 위젯에서 읽는 시험 기능을 제공합니다. Codex는 설치된 공식 CLI의 app-server에서 사용량을 조회합니다. 설정의 `Codex 브라우저 연결`은 사용자가 선택할 때만 공식 브라우저 로그인을 시작하고 완료 후 새로고침합니다. 인증 정보는 각 공식 앱이 관리합니다. 앱이 다시 로그인하지 않아도 되는 기간은 제공자의 세션 정책에 따라 달라집니다. 실계정 인증 완료와 Claude 실계정 상태줄 연결은 아직 테스트하지 않았습니다.

## macOS 빌드

macOS 13 이상, Apple Command Line Tools와 Python 3가 필요합니다. `bash build.sh`를 실행하면 계산·인증·모의 로그인 검사를 거쳐 `UsageEdge.app`이 만들어집니다. 로컬 자체 서명 빌드이므로 배포 서명과 공증을 하지 않습니다. Swift 및 SDK 환경에 따라 빌드 스크립트의 SDK 경로를 조정해야 할 수 있습니다.

1. 소스 압축을 풀고 터미널에서 풀린 폴더로 이동합니다.
2. `bash build.sh`로 앱을 만듭니다.
3. `open UsageEdge.app`으로 실행합니다. 메뉴 막대의 원형 아이콘에서 위젯을 숨기거나 다시 표시할 수 있습니다.
4. Codex CLI를 설치하고 로그인한 상태라면 사용량 조회를 시도합니다. 연결이 필요할 때만 위젯 설정에서 `Codex 브라우저 연결`을 선택합니다.

현재 빌드는 Apple Developer ID 서명과 공증이 없는 시험판입니다. 다른 Mac의 보안 설정에 따라 실행이 제한될 수 있으며, 실제 재부팅과 시작 시 실행은 검증하지 않았습니다.

모의 로그인 검사는 실제 계정이나 브라우저를 사용하지 않고 로그인 성공, 실패, 잘못된 주소, 서버의 조기 종료, 취소와 로그인 중 진행되던 오래된 조회가 완료된 뒤 새 사용량을 다시 조회하는 흐름을 확인합니다. 알림을 보내지 않으며 실제 브라우저 인증이나 서비스의 실제 사용량 조회를 검증하는 검사는 아닙니다.

같은 통합 검사는 임시 폴더의 모의 Claude 상태줄 데이터가 수집 스크립트에서 위젯 모델까지 전달되고 오래된 값이 처리되는지도 확인합니다. 실제 계정이나 화면 렌더링을 검증하지는 않습니다.

## Claude Code 상태줄 연동 시험

Claude Code의 [공식 상태줄 기능](https://code.claude.com/docs/en/statusline)은 Pro·Max·Ultra 구독자에게 5시간·7일 사용량을 전달할 수 있습니다. Claude Code 세션의 첫 응답 이후에만 값이 나타날 수 있고, 각 항목이 누락될 수 있습니다. Claude Code를 사용하지 않는 동안 자동으로 갱신된다는 보장은 없습니다.

연동하려면 이 폴더에서 아래 명령을 직접 실행합니다. Claude Code 설정의 다른 항목은 유지하며, 기존 상태줄이 있거나 설정을 읽을 수 없으면 변경하지 않고 중단합니다. 앱이 자동으로 설정하지는 않습니다. 연결 후 이 소스 폴더를 옮기면 설정의 `statusLine.command` 경로를 직접 수정해야 합니다. 아직 실계정 연결과 화면 표시를 검증하지 않았습니다.

```bash
python3 Tools/setup_claude.py --install
```

상태줄 스크립트는 `Claude`를 출력합니다. 기존 상태줄을 사용 중이라면 자동 설치하지 않으므로 아래 예시와 기존 명령을 직접 결합해야 합니다.

`~/.claude/settings.json`에 상태줄이 없는 경우 설정 항목 예시는 다음과 같습니다. `/실제/경로`는 소스 폴더의 실제 절대 경로로 바꿔야 합니다.

```json
{"statusLine": {"type": "command", "command": "python3 '/실제/경로/UsageEdge-공개준비/Tools/claude_status.py'"}}
```

이미 다른 설정 항목이 있으면 파일 전체를 교체하지 말고 해당 항목만 추가하세요.

스크립트는 사용률과 초기화 시각만 `~/Library/Application Support/UsageEdge/ClaudeStatus/snapshot.json`에 현재 사용자만 읽을 수 있게 저장합니다. 세션 ID와 대화·인증 정보는 저장하지 않습니다. 위젯은 15분이 지난 값을 `오래된 값`으로 표시하고 24시간이 지난 값은 지웁니다. 여기서 지우는 것은 화면 표시이며 파일은 그대로 남습니다. 연동 해제는 Claude Code 상태줄 설정을 복원하고 해당 파일을 삭제하면 됩니다.

## 공개 전에 남은 일

- 코드·자료의 권리 검토와 기여자 저작권 표시 확인.
- Claude 상태줄 연동의 실계정·정책 적합성 검토 및 데이터 갱신 한계 확인. 직접 계정 토큰을 조회하지 않습니다.
- 실계정·재부팅·오류 복구·알림·다중 모니터 테스트. 현재 빌드 및 계산 테스트만 수행했습니다.
- Windows는 별도 시험판으로, 실제 Windows 실행과 계정 연동을 검증하지 못했습니다.
- Apple Developer ID 서명 및 공증, 릴리스 배포 체계, 보안 신고 경로 마련.
- 사용자의 계정 ID, 인증 정보, 로컬 경로 등 비공개 정보가 커밋 또는 배포물에 포함되지 않는지 별도 점검.

이 프로젝트는 OpenAI, Anthropic 또는 UsageScope의 공식 제품이 아닙니다.

소스 코드는 [MIT 라이선스](LICENSE)로 공개할 수 있도록 준비했습니다. Windows 시험판 소스와 별도 사용 안내는 `Windows` 폴더에 있습니다.

## 인증 및 공개 검증 상태

Codex 공식 app-server에서 브라우저 로그인 시작 응답과 취소 요청은 기존 계정으로 확인했습니다. 브라우저는 열지 않았고 실제 로그인을 완료하지 않았습니다. 다른 호스트·일반 HTTP·누락된 ID 및 잘못된 성공값을 거르는 검사를 통과했습니다. 실제 브라우저 인증 완료와 계정 전환, 취소, 장기간 자동 갱신은 미검증입니다. 임시 앱 식별자는 공개 전 소유자의 고유 식별자로 변경해야 합니다.

Anthropic의 현재 [인증 정책](https://code.claude.com/docs/en/legal-and-compliance)은 타사 앱의 Claude 계정 토큰 중개에 제한을 둡니다. 자동 조회를 제공하기 전에는 허용된 공식 경로와 사용량 데이터의 접근 가능성을 확인해야 합니다.

미리보기 앱 실행 후 화면 확인 도구가 시간 초과되어 공개 준비본 UI는 이번 빌드에서 확인하지 못했습니다. 현재 사용 중인 개인용 앱은 변경하지 않았습니다.

초기화 시각이 제공될 때 펼친 위젯에 남은 시간을 표시합니다. 예정 시각을 지나면 새 응답이 오기 전까지 `초기화 확인 중`으로 표시하며 한도 갱신을 추정하지 않습니다. 인증 취소 뒤 늦게 도착한 응답은 무시하도록 처리했으며 관련 로직은 단위 검사로 확인했습니다. 실제 브라우저 인증 취소와 장시간 재접속은 아직 실사용으로 확인하지 못했습니다.

인증 시작 직전 취소된 요청은 브라우저를 열지 않도록 처리했습니다. 진행 중 취소·앱 종료 때 인증 프로세스도 종료하도록 구현했지만 실제 브라우저와의 통합 검증은 남아 있습니다.
