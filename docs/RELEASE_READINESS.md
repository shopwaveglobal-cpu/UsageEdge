- 실제로 데이터를 받지 못하는 제공업체는 연결 가능 또는 실시간 수치 제공으로 홍보하지 않습니다.
- 리셋 시각은 제공자의 예정값이며 실제 초기화 여부와 별도로 설명합니다.
- 공개 릴리스에는 검증한 정확한 커밋의 소스와 아티팩트를 연결하고 SHA-256을 제공합니다.
- macOS 공증이 없는 경우 정식 공증 앱으로 안내하지 않습니다. Windows 스크립트의 실행 정책 우회와 서명 여부를 명시합니다.
- 계정별 인증 정보, 대화, 개인 경로와 실사용 진단 파일은 저장소와 배포물에 넣지 않습니다.
