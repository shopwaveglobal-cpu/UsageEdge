# UsageEdge Windows 시험판

Windows 10/11용으로 작성한 시험판입니다. 이 파일은 macOS에서 제작했으며 실제 Windows 실행과 Codex 연결은 아직 검증하지 못했습니다. 공유 전 Windows PC에서 확인이 필요합니다.

## 시작

1. 압축을 풀고 폴더를 옮기지 않을 위치에 둡니다.
2. Windows에 Codex CLI를 설치합니다. `codex` 명령이 동작해야 합니다. 기존에 로그인되어 있으면 그 계정을 사용합니다.
3. `실행.cmd`를 더블 클릭합니다. 위젯이 화면 오른쪽 중앙에 나타나며, 화살표로 접거나 펼칠 수 있습니다.
4. 연결이 필요하면 설정의 `Codex 브라우저 연결`을 선택해 공식 CLI의 브라우저 로그인 절차를 진행합니다. 로그인 완료 후 사용량을 다시 조회합니다. 설정에서 로그인 시 실행, 알림 테스트, 종료도 선택할 수 있습니다. 알림은 Windows 알림과 집중 모드 설정에 영향을 받습니다.

`실행.cmd`는 해당 실행에 한해 PowerShell 실행 정책을 우회합니다. 스크립트에 전자 서명이 없으므로 Windows에서 차단하거나 경고할 수 있습니다. 파일 출처와 내용을 확인한 뒤 사용하세요. 시스템 전체 실행 정책은 변경하지 않습니다. 자동 실행은 현재 사용자 시작 폴더에 바로가기를 만들며 앱 폴더를 이동하면 다시 설정해야 합니다.

## 기능과 한계

- Codex: 해당 PC의 Codex CLI가 반환한 한도와 초기화 시각만 표시합니다. 5분마다 갱신합니다. CLI가 없거나 로그인/네트워크에 문제가 있으면 확인 불가로 표시합니다.
- 위젯을 접으면 Codex의 5시간·주간 잔여량을 표시합니다. 해당 값을 받지 못한 항목은 `—`로 표시합니다. 창 크기와 글자 배치는 Windows 디스플레이 배율에서 아직 실기기 검증하지 않았습니다.
- 알림: **앱 실행 중에만**, 마지막으로 조회한 초기화 예정 시각에 Windows 트레이 알림을 표시합니다. 실제 한도가 갱신됐는지는 새로고침해서 확인해야 합니다. 앱이 종료됐거나 PC가 꺼진 동안은 알림이 보장되지 않습니다. 재실행 직후 같은 예정 시각에 대한 알림이 반복될 수 있습니다.
- Claude: 계정 토큰을 읽거나 저장하지 않습니다. 위젯의 Claude 문구를 누르면 공식 사용량 페이지가 열립니다. 위젯 내 실제 Claude 잔여량과 리셋 알림은 미구현입니다. [Anthropic 공식 인증 정책](https://code.claude.com/docs/en/legal-and-compliance)의 타사 앱에 관한 제한을 검토했습니다.
- Kimi Code: 설정의 `Kimi Code 연결…`에서 실행 중인 로컬 서버 포트를 입력하면 Kimi가 저장한 로컬 서버 토큰을 읽어 조회합니다. 이 토큰은 서버의 파일·명령 기능에도 접근할 수 있으므로 포트가 Kimi 서버인지 확인해야 합니다. 설정에는 포트만 저장합니다. 사용량과 초기화 시각은 서버가 제공하는 경우에만 표시합니다. 서버 API는 베타이며 실제 계정과 Windows PC에서의 연결·알림은 아직 검증하지 않았습니다.
- 계정 비밀번호, API 키, 인증 토큰을 다른 사람에게 보내지 마세요. 이 앱은 Codex 로그인 정보를 직접 읽거나 저장하지 않고 공식 Codex CLI에 조회를 요청합니다.

## 검증

PowerShell 구문과 가상의 Codex 응답 계산은 macOS PowerShell에서 확인했습니다. 브라우저 연결 메뉴는 공식 `codex login` 명령을 실행하도록 작성했으나 Windows에서 테스트하지 않았습니다. Windows의 UI, CLI 호출, 알림, 시작 시 실행과 실제 계정은 테스트하지 않았습니다. `검사.ps1`을 실행하면 계산 검사를 다시 할 수 있습니다. 인증은 CLI가 관리하며, 세션 만료 시 다시 로그인이 필요할 수 있습니다.
